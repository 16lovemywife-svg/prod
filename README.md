# 🥗 RecipeCalc

**RecipeCalc** — это офлайн-веб-приложение для хранения кулинарных рецептов с автоматическим расчётом калорийности, белков, жиров, углеводов (КБЖУ) и стоимости блюд.  
Приложение предназначено для персонального использования на локальном компьютере, не требует регистрации и работает полностью без интернета.

## 📋 Основные возможности

- 📦 **База продуктов** – добавление и редактирование ингредиентов с указанием КБЖУ и цены (за кг, литр, штуку и т.д.)
- 📝 **Управление рецептами** – создание, редактирование и удаление рецептов с пошаговыми инструкциями и таймерами
- 🔢 **Автоматический расчёт КБЖУ** – на порцию, на 100 г и на всё блюдо; пересчёт при изменении количества порций
- 💰 **Расчёт стоимости блюда** – фактическая стоимость использованных продуктов и полная стоимость с учётом минимальной покупки целых упаковок
- 📊 **Детализация стоимости** – таблица с разбивкой по каждому ингредиенту
- ⚖️ **Масштабирование порций** – ползунок и кнопки ± мгновенно пересчитывают все количества, КБЖУ и стоимость
- ❤️ **Избранное** – возможность добавлять рецепты в избранное и просматривать их отдельно
- 🔥 **Режим готовки** – полноэкранный режим с крупными шагами, встроенными таймерами и защитой от выключения экрана
- 🔍 **Поиск и фильтрация** – поиск по названию/тегам, фильтр по сложности, пагинация
- 🎨 **Современный неоновый интерфейс** – тёмная тема с яркими акцентами
- 💾 **Полностью офлайн** – все данные хранятся в локальной базе SQLite, фото сохраняются на диск


## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/16lovemywife-svg/prod.git
cd prod
2. Установка зависимостей
Требуется Python 3.9 или выше. Рекомендуется использовать виртуальное окружение.

bash
python -m venv .venv
source .venv/bin/activate   # для Linux/Mac
# или
.venv\Scripts\activate      # для Windows

pip install -r requirements.txt
3. Запуск приложения
bash
python app.py
Откройте браузер и перейдите по адресу: http://127.0.0.1:5000

4. Наполнение базы данных (опционально)
Для быстрого добавления продуктов и рецептов выполните скрипты (при необходимости):

bash
python seed_all.py          # добавит базовые продукты и несколько рецептов
python update_prices.py     # установит ориентировочные цены для продуктов
📚 Использование
Продукты
Перейдите в раздел Продукты (📦)

Добавьте новый продукт, указав название, категорию, КБЖУ на 100 г, цену и за что она указана (кг, л, шт и др.)

Все продукты отображаются в таблице с возможностью поиска, фильтрации и редактирования

Рецепты
Нажмите Добавить рецепт (➕)

Заполните основную информацию, добавьте ингредиенты (выбирая из базы продуктов) и пошаговые инструкции

На странице рецепта вы увидите автоматически рассчитанные КБЖУ и стоимость

Изменяйте количество порций – ползунок или кнопки ± мгновенно пересчитают все цифры

Сворачивайте блоки «Ингредиенты», «Приготовление» и «Стоимость» для удобства

Режим готовки (🔥) открывает полноэкранный интерфейс с таймерами для каждого шага

Избранное
На странице рецепта нажмите ❤️, чтобы добавить в избранное

В навигации выберите ❤️ Избранное – отобразятся только избранные рецепты

Поиск и фильтры
На главной странице используйте поисковую строку для поиска по названию и тегам

Фильтруйте рецепты по сложности (лёгкие, средние, сложные)

🗂 Структура проекта
text
recipecalc/
